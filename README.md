# Build and deploy gen AI applications on Google Cloud with Genkit and Node.js
[Google Developers Codelabs](https://codelabs.developers.google.com/)

[Automatically Deploy Generative AI Node.js Genkit Web Application from Version Control to Cloud Run](https://codelabs.developers.google.com/codelabs/deploy-from-github/genkit-nodejs)

In this lab, you write a web application and configure [Cloud Run](https://cloud.google.com/run) to automatically deploy your application when a change is made to the source code of your application. Then you modify your application and deploy it again.

This [website](https://codelab-genai-649048930651.us-central1.run.app) shows  10 fun facts about an animal. Eg: [flamingo](https://codelab-genai-649048930651.us-central1.run.app?animal=flamingo)
